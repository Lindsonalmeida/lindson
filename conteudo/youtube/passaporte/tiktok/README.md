## Como reaproveitar os Shorts
- Usar o mesmo MP4 vertical do Short (sem marca d'água de outra plataforma), 45 a 70 s, com o áudio original.
- Capa: a capa vertical do Short (`../capas/`), sistema aprovado do `capas2.py`.
- **Legenda curta:** 1 frase-gancho + pergunta para comentar. Ex.: "Por que Deus pediu Isaque a Abraão? Comenta o que você acha 👇"
- **3 a 5 hashtags, variar sempre** (tema + nicho + geral): `#biblia` `#estudobiblico` `#historiabiblica` + do livro (`#genesis`, `#apocalipse`, `#jesus`, `#oracao`, `#planodeleitura`) + `#fe` ou `#bibliatok`. Base: as tags que já rodam no `shorts.json`. Nunca o mesmo bloco duas vezes seguidas.
- Não colocar `#shorts` no TikTok.
- Imagem de IA: escrever "imagem gerada por IA" na legenda.
