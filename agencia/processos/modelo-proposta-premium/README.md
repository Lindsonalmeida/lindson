# Processo: proposta premium, um modelo novo para cada cliente

> **Regra do Lindson (07/11/2026): "sempre que eu pedir template ou identidade premium, faça o mesmo processo que fez pro dublê e real time."** Vale para proposta, template, identidade, manual e peça premium. O checklist está em `MEMORIA-DO-LINDSON.md`, seção 2, item 0b.

**Regra do Lindson (07/11/2026, conta Lindson): "cada cliente, crie um modelo premium novo, sempre."**

Não existe um modelo único reaproveitado. Cada cliente ganha o seu, feito do zero para a persona dele, com pesquisa nova.

## Passo a passo (vale para todo cliente)
1. **Persona em 5 linhas** (`agencia/processos/persona.md`): quem é, rotina, dor e desejo com as palavras dele, o que faz confiar, o que afasta.
2. **Pesquisa premium** (`agencia/processos/pesquisa-premium.md`): no mínimo 8 referências de 3 países, com captura de tela salva na pasta do cliente. Escolher as 3 mais fortes para aquele cliente e dizer o que se copia de cada uma.
3. **Registrar no `TEMPLATE.md` da pasta do cliente**: as 3 escolhidas (com motivo), as descartadas (com motivo) e o estado honesto da pesquisa. Referência que não abriu, ou sem prêmio confirmado, fica marcada "não conferido".
4. **Modelo novo na pasta do cliente**, não copiado de outro cliente. Ex.: `agencia/prospeccao/<cliente>/proposta-premium/`.
5. **Conferência antes de mostrar**: parece trabalho de estúdio premiado? Aguenta ao lado das 3 referências? Se não, refaz.
6. **Mostrar ao Lindson** as 3 referências junto com a entrega.
7. **Sem preço nos planos** (valores na conversa), sem número inventado, sem compromisso que o Lindson não aprovou (fidelidade, vagas, prazo de saída, garantia).

## Por que existe
Na proposta do Wagner Silva (07/11/2026) a primeira versão foi feita sem pesquisa suficiente e com compromissos inventados, que tiveram de sair. Este processo existe para isso não se repetir.
