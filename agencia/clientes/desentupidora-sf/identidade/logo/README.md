# Logo da Desentupidora SF · arquivos e manual (conta Lindson, 14/11/2026)

- `arquivos/original/` logo original reconstruída em alta (Real-ESRGAN): 2048 e 4096 px, transparente.
- `arquivos/svg/` e `arquivos/png/` versão plana vetorial: símbolo, horizontal, vertical (colorida, negativa, azul, branca, preta), selo, ícone de perfil, favicon.
- `gerar-logo.py` gera os SVGs (textos em curva via `glyphs.py`); `render-png.js` gera os PNGs.
- `manual/gerar-manual.py` + `manual.css` → `manual.html`; PDF com `pdf.js` (scratchpad) → `Manual-da-Logo-Desentupidora-SF.pdf` (16 págs, 1920x1080).
