# Fusão dos 10 sites bonitos (versão 3 do site do Wagner)

Pedido do Lindson (07/11/2026): "todos são lindos. faça uma fusão de todos".

**Regra de fusão:** um sistema, não um mosaico. Cada referência emprestou um elemento, com um limite claro.

| Referência | O que foi emprestado | Limite |
|---|---|---|
| Lusion | objeto central brilhante no herói | só um objeto por tela |
| Stripe | fita de gradiente azul-ciano no objeto e no botão principal | só nesses dois lugares |
| Locomotive | título grande e etiqueta em caixa com borda | uma etiqueta por bloco |
| Resn | título leve e centralizado com muito espaço | sem texto disputando |
| Linear | cartões de planos com cabeçalho de janela de produto | só nos planos |
| Framer | paleta escura com acento azul | sem azul elétrico fora do herói |
| Studio Dumbar | número grande como peça tipográfica | só no número de destaque |
| Pentagram | legenda pequena sob o número, com fio | sem serifa de escritório |
| Koto | fundo preto e texto mínimo | sem amarelo |
| Obys | índice numerado com fio fino | sem a grade cinza |

**Sistema resultante:** fundo #07080A, texto #E9EEF2, acento ciano-azul (gradiente #7FD8E6 → #3D6BFF), tipografia Unbounded (títulos), Sora (texto), JetBrains Mono (rótulos).

**Verificado:** renderizado em 1440 px (sem rolagem horizontal) e 390 px (sem rolagem horizontal).
