# StepList

Passos numerados ligados por uma linha que vai de `signal` a `violet` a `sun`.

Forneça três passos, cada um com um verbo de ação no início e o trecho que a pessoa precisa reconhecer em `<b>` (`sun`). No Story, abaixo de cada título entra um exemplo visual real (o perfil, o botão, a conversa). Mais de três passos: divida em duas peças.
