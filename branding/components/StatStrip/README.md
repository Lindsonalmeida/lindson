# StatStrip

Faixa de três números que dá autoridade: anos de conteúdo, seguidores e território.

Forneça exatamente três `.la-stat`, cada um com o número em `<strong>` (Bricolage 800) e o rótulo em `<span>` (mono, caixa alta, `muted`). Use números reais e atualizados, com vírgula decimal ("9,1 mil"). Nos Stories, a mesma faixa cresce para `story-number`.
